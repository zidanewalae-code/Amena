# Amena
Texte pour README (1–2 courts paragraphes) : AMENA est une plateforme web pour gérer les dons, les bénéficiaires, les commandes de distribution et les paiements. Le backend (Node.js + Express + Sequelize) expose une API REST sur MariaDB ; le frontend (React + Vite) fournit des tableaux de bord pour les rôles admin, donateur et livreur.
